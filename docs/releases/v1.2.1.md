Cette version sert uniquement à tester le bouton **Chercher une mise à jour** dans le panneau Creator Bridge de Premiere Pro. Le numéro de version passe à 1.2.1. Les fonctionnalités sont identiques à la 1.2.0.

Le fichier CCX sert à l’installation via Creative Cloud. ClipFlow et Capture8K utilisent le ZIP pour leur fonction de mise à jour du panneau.

## English

This version-only release lets you test **Check for updates** in the Creator Bridge panel. Use the CCX for Creative Cloud installation. The ClipFlow and Capture8K updaters use the ZIP.
