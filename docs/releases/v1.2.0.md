Creator Bridge 1.2.0 réorganise le panneau Premiere Pro autour du projet actif, du dernier import et de la version installée.

- **Chercher une mise à jour** vérifie uniquement Creator Bridge. Quand une nouvelle version stable est disponible, le panneau propose sa page GitHub.
- Le résultat du dernier import reste visible tant que le même projet est actif.

Pour mettre à jour le panneau via Creative Cloud, ouvrez `CreatorBridge-v1.2.0.ccx` avec l’installateur Adobe. Les programmes de mise à jour de ClipFlow et Capture8K utilisent l’archive ZIP.

## English

Creator Bridge now shows the active project, the latest import and the installed version separately. The panel’s update button checks Creator Bridge releases. Use the CCX for a Creative Cloud installation or let the ClipFlow or Capture8K updater install the ZIP.
